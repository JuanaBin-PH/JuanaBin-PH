# JuanaBin-PH 🇵🇭
Smart waste segregation system with IoT connectivity and solar-ready design for Philippine communities.

JuanaBin is an affordable, solar-powered smart bin designed for barangays, schools, and condos in the Philippines to automate waste segregation.

### ✨ Features
- Automatic segregation: Biodegradable / Non-Biodegradable / Recyclable
- IoT fill-level monitoring (real-time alerts)
- Solar-ready power system
- Low-cost & locally sourced materials

### 🛠️ Tech Stack
- ESP32 / Arduino
- Ultrasonic Sensor, IR Sensor, Servo Motors
- Firebase / MQTT

### 📁 Project Structure
- `/firmware` - ESP32/Arduino code
- `/hardware` - wiring & 3D model
- `/mobile-app` - monitoring app (optional)

### 🚀 Getting Started
1. Clone the repo
2. Upload firmware to ESP32
3. Configure WiFi credentials

### 🌏 For Philippine Communities
Designed to support RA 9003 (Ecological Solid Waste Management Act)
