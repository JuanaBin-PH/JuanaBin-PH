# 06 — Budget Justification — $5,000 USD Instaward

## 8.1 Budget Breakdown

| Budget Category | Amount (USD) | Justification |
| --- | --- | --- |
| **Stellar Development — Wallet, Token, SDK** | $1,800 | Lead blockchain developer: 60 hours @ $30/hr. Stellar Python SDK integration, JBIN asset deployment, Kinde-Stellar authentication bridge, Testnet-to-Mainnet migration planning (Aug 25 – Sep 25, 2026). |
| **Backend — Reward Logic Engine** | $1,200 | Full-stack developer: 40 hours @ $30/hr. Python reward calculation engine, waste intake form, Stellar payment dispatch, duplicate prevention system, database integration. |
| **Frontend — Dashboard & Pilot UI** | $900 | Frontend developer: 30 hours @ $30/hr. Admin dashboard, public transparency page, LGU export function, mobile-responsive household UI, video walkthrough production. |
| **Community Pilot Coordination** | $600 | Community liaison (Buslo ng Pag-asa coordinator): Household onboarding during Sep 8–14, 2026, waste collection coordination, Kinde signup assistance for low-literacy participants. |
| **Infrastructure & Tools** | $300 | Cloud hosting (staging + pilot deployment Aug 25 – Sep 25, 2026), domain name, SSL certificate, Stellar Testnet faucet XLM (via Friendbot), CI/CD tooling. |
| **Documentation & SCF Submission** | $200 | Technical writing, README documentation, LGU compliance report formatting, SCF forum post preparation, evidence package compilation (delivery by Sep 25, 2026). |
| **TOTAL** | **$5,000** | **Full Instaward budget utilized for direct development and pilot delivery** |

> **Cost-Effectiveness Note:** The $5,000 Instaward funds the complete technical foundation for a platform that, at 1,000 households, generates ~2,400 kg CO²e offset per month, ~PHP 500,000–2,000,000 in annual household income, and onboards 1,000 previously unbanked Filipinos onto the Stellar network — representing an exceptional return on SCF investment. Every dollar spent in this sprint directly enables measurable financial inclusion and climate impact at Philippine barangay scale.

## 8.2 Instawards Program Constraints — Acknowledgement

- [ ] **Hard Deadline:** All three deliverables and evidence must be submitted to the SCF Instawards team by **September 25, 2026**. No extensions without prior written SCF approval.
- [ ] **On-Chain Evidence Required:** Completion is not acknowledged based on verbal or written claims alone. All technical deliverables must be evidenced by Stellar Explorer transaction URLs, GitHub commit hashes, and/or publicly accessible URLs.
- [ ] **No Speculative Tokens:** JBIN tokens are non-tradeable, non-speculative utility tokens. JBIN will not be listed on any exchange, marketed as an investment, or used to raise external capital.
- [ ] **Open-Source Code:** All code produced under this Instaward will be published to a public GitHub repository under MIT License within the sprint window, as required by SCF Instawards terms.
- [ ] **Stellar Network Exclusivity:** This engagement is Stellar-native. No multi-chain bridges or alternative blockchain deployments are planned within this sprint (Aug 25 – Sep 25, 2026).
- [ ] **Testnet Scope:** This sprint operates on Stellar Testnet. Mainnet migration is planned for Phase 1, pending SCF grant approval. Testnet transactions are fully valid as Instawards evidence.
- [ ] **SCF Forum Reporting:** JuanaBin PH will post weekly progress updates to the SCF Community Forum throughout the engagement (Aug 31, Sep 7, Sep 14, Sep 21, 2026), plus a final completion report on September 25, 2026.
